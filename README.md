# cms.premium
Working with CMS data to create dashboards that present useful insights about Medicare Premiums in 2023 (most recent data available). 

The focus of these dashboards were Medicare Premium Part B Amounts and Beneficiaries.

I imported the Excel tables into R and created a dataset to use in Tableau.

Dashboards: https://public.tableau.com/views/PartB_Premiums/Story1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

Data Source: https://data.cms.gov/summary-statistics-on-use-and-payments/medicare-premium-reports/cms-program-statistics-medicare-premiums
